# project-harmony

Project Harmony — a Root-to-Tip ecosystem framework connecting research, education, agriculture, natural capital, accountability, and community development through evidence-based planning and explicit claim-discipline standards.

## What's here

- **kml-pipeline-spec/** — Proposed architecture for an origin-preserving field-to-gate tracking pipeline: KML polygon ingestion and validation (PostGIS + Shapely), a farmer upload portal, SHA-256 polygon hashing, HMAC-verified scale-house payloads, and a cradle-to-gate LCA metric engine. Design stage — not deployed.
- **mrv/** — `provenance_distiller.py` (bot-managed — ask Muse before editing): hash-chained MRV batch envelopes + JSONL ledger.
- **.github/** — deterministic bot kit workflows.

## Status

All pilots, academies, and replication plans are proposed or research-stage. Nothing here represents a deployed system, measured field dataset, or operating facility.
